## 📌 Sobre

A **Brasil GO** é um protótipo front-end de uma plataforma de viagens nacionais: a interface simula a busca de destinos, o fluxo de reserva (tipo de viagem, origem, destino, datas e passageiros), o cadastro/login e a área "Minhas viagens".

> ⚠️ **Projeto de estudo / demonstração.** Não há back-end nem banco de dados: cadastro, login, newsletter e perfil são simulados e **nenhum dado é enviado ou armazenado**. Preços, avaliações, depoimentos e números de clientes são **fictícios**.

Projeto final do curso de Front-End — **Programa PROA + Serasa Experian**, desenvolvido pela turma Grupo 4 em 2026.

## 🗂️ Páginas

- 🏠 **Home** — apresentação da plataforma e destaque dos diferenciais
- 🔐 **Login** — acesso à conta do usuário
- 📝 **Cadastro** — criação de nova conta
- ✈️ **Menu de Viagens** — listagem de destinos disponíveis
- 📋 **Minhas Viagens** — histórico de viagens marcadas e canceladas
- 👤 **Perfil** — visualização e edição dos dados cadastrais
- 🔍 **Busca** — filtro de destinos por nome na página de destinos

---

## 🛠️ Tecnologias

HTML5 semântico, CSS3 (Flexbox, Grid, media queries), JavaScript (DOM, eventos), [AOS](https://michalsnik.github.io/aos/) para animações de rolagem e Font Awesome para ícones.

## ▶️ Como executar

Não há etapa de build. Clone o repositório e abra `index.html` no navegador, ou sirva a pasta com qualquer servidor estático (por exemplo, a extensão *Live Server* do VS Code).

```bash
git clone <url-do-repositorio>
cd BrasilGo
# abra o index.html ou use o Live Server
```

## 📁 Estrutura

```
index.html            página inicial
css/, js/             estilos e scripts da home
assets/               imagens e ícones
pages/destinos        lista de destinos, busca e modal de detalhes
pages/origem-parte2   fluxo de reserva (passos 1 a 5)
pages/login, cadastro, cadastrook, perfil, minhasviagens
```
